# Item Sharing Association (ISA) - Java System Design

## Overview
An object-oriented system design for a community sharing scheme managing books, DVDs, and members. Built to comply with SOLID design principles and allow seamless expansion for new media types.

## Role
**Student Team Lead / Systems Architect**
* Coordinated group architecture planning and UML diagram generation.
* Designed dynamic file-parsing and data-persistence models.
